Diapositives de sondage pour Excalidraw+

Choisissez une banque. Le bouton produit un fichier .excalidraw : une diapositive « question » et une diapositive « résultats » par question. Importez-le dans Excalidraw+ (menu → Ouvrir), puis copiez les diapositives voulues dans votre présentation.
